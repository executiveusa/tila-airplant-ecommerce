# Tila logo intro / Intro del logotipo Tila

Local Hyperframes composition. Install the pinned npm dependencies, then supply the licensed Bricolage Grotesque font from the site build as assets/logo-font.woff2 and add its local font-face rule before rendering. No private media is stored here.

Composición local de Hyperframes. Instale las dependencias npm fijadas y use la fuente Bricolage Grotesque del sitio antes de renderizar. No contiene medios privados.
