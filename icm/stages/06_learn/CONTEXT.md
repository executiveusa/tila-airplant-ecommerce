# Stage 06 - Learn (weekly)
**Read:** all `icm/memory/` ledgers for the last 7 days.
**Do:** write `output/<date>-review.md`: what sold (by lot), questions that repeat, shipping results by zone/carrier, listing views vs sales if available, and at most 3 proposed changes with evidence.
**Gate:** proposals only. The owner of each side approves the changes on that side; approved changes route back to stages 02-05.
**Memory:** lessons that held up -> `lessons.md`.

## ES-MX (semanal)
**Hacer:** redactar `output/<fecha>-review.md` con lo vendido por lote, preguntas repetidas, resultados de envío por zona y paquetería, visitas contra ventas si hay datos, y como máximo 3 propuestas con evidencia.
**Control:** solo propuestas; cada persona responsable aprueba los cambios de su lado.
**Memoria:** los aprendizajes confirmados van a `lessons.md`.
