# Tila memory
Append-only ledgers. Newest entries at the bottom. Every entry has a date and a source (order id, ML question id, owner message date, URL).
| File | What goes in |
|---|---|
| `decisions.md` | Owner approvals and rulings, with the date and where he said it |
| `open-questions.md` | Things only the owner or an outside party can answer |
| `shipping-carriers.md` | Carrier rules found + every shipment result |
| `sales-log.csv` | One row per sale |
| `buyer-questions.md` | Questions asked and the approved answers |
| `price-moves.csv` | Every price/lot proposal and decision |
| `lessons.md` | Patterns that held up across more than one event |

## ES-MX
Bitácoras de solo agregar; lo más reciente al final. Cada entrada lleva fecha y fuente. `decisions.md`: aprobaciones y acuerdos de las personas responsables (con sus palabras y dónde lo dijeron) | `open-questions.md`: pendientes que solo pueden responder las personas responsables o terceros | `shipping-carriers.md`: reglas de paqueterías y resultado de cada envío | `sales-log.csv`: una fila por venta | `buyer-questions.md`: preguntas y respuestas aprobadas | `price-moves.csv`: cada propuesta y decisión de precio | `lessons.md`: patrones confirmados en más de un caso.
