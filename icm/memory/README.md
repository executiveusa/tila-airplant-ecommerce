# Tila memory
Append-only ledgers. Newest entries at the bottom. Every entry has a date and a source (order id, ML question id, owner message date, URL).
| File | What goes in |
|---|---|
| `decisions.md` | Owner approvals and rulings, with the date and where he said it |
| `open-questions.md` | Things only the owner or an outside party can answer |
| `shipping-carriers.md` | Carrier rules found + every shipment result |
| `sales-log.csv` | One row per sale |
| `buyer-questions.md` | Questions asked and the approved answers |
| `price-moves.csv` | Every price/lot proposal and decision |
| `lessons.md` | Patterns that held up across more than one event |
